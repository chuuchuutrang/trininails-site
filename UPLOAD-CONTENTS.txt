TRININAILS.STUDIO — DEPLOYMENT COPY

The live website is published from the public GitHub repository:
https://github.com/chuuchuutrang/trininails-site

Use scripts/publish_site.py from the private source repository to check and
publish deploy-ready/ safely. GitHub Pages serves the public repository, while
Porkbun manages the trininails.studio domain and DNS.

After publishing, verify:
1. https://trininails.studio/
2. https://trininails.studio/guide/
3. https://trininails.studio/study/
4. https://trininails.studio/money/
5. https://trininails.studio/manners/
6. https://trininails.studio/print/
7. The booking links, language toggles, print downloads, and mobile layout

This folder is fully static. It does not require Node.js, Python, PHP, WordPress,
or a database on the web host. Rebuild it with:

python3 scripts/render_all.py

Then publish it with:

python3 scripts/publish_site.py --apply --commit --push --message "Publish site updates"
